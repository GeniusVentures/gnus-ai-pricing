Assumptions & Methodology

Pricing Sources

GPU rental prices are illustrative reference inputs selected for February 2026, not automatically updated quotes. GNUS.ai comparison values were supplied as modeled effective-throughput inputs in the original project request; no independently verified production network measurements were supplied.

GPU Utilization

All GPU calculations assume 60% utilization. This is an illustrative scenario input, not measured utilization of the listed providers. Real throughput depends on device, precision, workload, batching, memory limits and sustained duty cycle.

Precision Multipliers

This model uses separate per-precision peak throughput estimates for each GPU and different fixed GNUS modeling inputs. FP32, FP16, FP8 and adaptive low-bit workloads are not interchangeable: kernel support, quantization, model dimensions and memory pressure affect realized performance. "Blended" values are scenario assumptions, not benchmarked latency or tokens/second.

GNUS.ai Pricing Model

This table models a proposed idle-device inference supply, not live public-mainnet pricing. GNUS.ai's fixed 200/600/1400/3500/2200 reference values came from the February 2026 planning brief and are not observed network performance. The "TFLOPS per $1/hr" display divides modeled useful TFLOPS by assumed hourly cost; the reverse view calculates USD per 1,000 effective TFLOPS-hours as 1000 / (effective TFLOPS per $1/hour). The numerator is a quantity of compute throughput, not $1,000 of spending. See pricing-methodology and unit definitions. A proposed $0.0003 per active external ELM-hour is a separate planning assumption, not a substitute for these throughput inputs or a customer-facing API tariff.

Data Freshness

Source assumptions are dated February 2026. Rental prices change over time, and some GPU specification inputs are estimates. No matched-workload benchmarks or production-node traces were used to establish an exact GNUS-versus-GPU saving. Check current vendor rates and the applicable supported precision before comparing.
